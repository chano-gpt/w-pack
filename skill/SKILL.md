# Z-Pack public starter operation

1. Run `zpack doctor` before use.
2. This repository intentionally ships with no style, character, pose, proportion, or item images. Add only assets you own or are licensed to use; keep local authority images uncommitted.
3. Use explicit approved authority IDs. Do not identify or imitate living artists from style samples.
4. Keep generated candidates, evidence, and audit output outside the repository in the managed sibling workspace.
5. Use the built-in image-generation path; do not add API keys, credentials, or generated results to the repository.
6. Before publishing a fork, run `git status --ignored` and confirm that local authorities, presentation material, and generated outputs are absent from the staged change set.
