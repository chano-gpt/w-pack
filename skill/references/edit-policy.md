# Edit Policy

Use `EDIT` only when a usable target image exists and the user asks to modify, preserve, refine, restyle, or recompose it.

User-requested EDIT is separate from W-Pack's automatic FRESH style-recovery path.

## Edit types

- `MODIFY`: change selected properties while preserving the rest.
- `RESTYLE`: preserve requested content/structure while changing visual language.
- `RECOMPOSE`: preserve requested content while changing framing/layout.

Default Project sources remain active in ordinary user-requested EDIT unless explicitly disabled.

For non-STYLE roles, a same-role inline reference overrides the corresponding Project role for that request. An explicit inline STYLE replaces the Project STYLE family by default; combine style sources only when the user explicitly asks for combination.

Authority selection still does not prove visual transport. Do not claim exact preservation from an unverified or text-only reference path.

When editing hair, distinguish hairstyle geometry from hair rendering grammar. A request to clean up flyaways, split tips, or strand highlights is not permission to change length, parting, fringe, volume, curl pattern, or major lock placement unless the user asks for those changes.

Do not recursively edit without explicit user intent. A request to change one property is not permission to redesign unrelated properties.
