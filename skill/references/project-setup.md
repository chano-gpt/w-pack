# Project Setup

Use persistent ChatGPT Project sources as W-Pack's primary reference path.

## Recommended setup

1. Add reusable reference images to the Project.
2. Define bounded authorities in the manifest.
3. Define `source_profiles.DEFAULT`.
4. Set `default_source_profile` to `DEFAULT`.
5. Keep one STYLE authority in the normal DEFAULT profile so it can act as STYLE_CORE.
6. Add W-Pack Project instructions.

The user should not need to reattach recurring sources or repeat "use the sources".

Use current-chat attachments for temporary overrides or additions.
