# Quick start

```bash
python3 -m pip install -e .
zpack doctor
zpack init
```

The public starter validates with zero authorities. To compile a request, first add and approve only rights-cleared local assets, then promote the relevant style sources through your own review process. Keep those images and their private review material out of Git.

Use `zpack asset add`, `zpack asset analyze`, and `zpack asset approve` for character, pose, proportion, and item authorities. Use the corresponding `zpack style` commands for style samples. The generated candidate and all review evidence must remain in `../zpack-workspace`.
